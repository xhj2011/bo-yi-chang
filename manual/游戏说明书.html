一、游戏简介

《博弈场》是一款多人网页卡牌/策略游戏，基于经典博弈论模型：囚徒困境、公共品、猎鹿、志愿者困境、信任博弈、少数者博弈、最后通牒、决斗、海盗分金、拍卖等。

玩家通过讨论、合作、背叛、发布真假情报和发动技能来获取最高分，最后分数最高者获胜。

二、快速开始

1. 打开游戏网址：http://182.92.127.15:3000

2. 输入昵称，点击“创建房间”，或输入房间号加入好友房间。

3. 可以点击“添加机器人”加入电脑玩家（最多8人）。

4. 选择难度：简单 / 普通 / 困难。困难模式包含隐藏职业、技能、情报系统和全局随机事件。

5. 房主点击“开始游戏”后，所有玩家进入身份选择阶段。

三、游戏流程

1. 身份选择：选择你的职业（激进者 / 保守者 / 幸运者 / 情报者）。

2. 技能选择：每个职业有多个主动技能，开局前选择 2~3 个。

3. 阅读阶段：阅读本局事件规则，确认后进入讨论。

4. 讨论阶段：玩家可以聊天、承诺、威胁、撒谎，也可以发布待公开信息。

5. 情报阶段：如果有人提交了信息，会先进入情报阶段，情报者可以处理待公开信息。

6. 选择阶段：根据当前博弈事件做出秘密选择。

7. 结算：公布本轮结果、分数变化，然后进入下一轮。

8. 所有轮次结束后，总分最高者获胜。

四、四大职业

【激进者】

被动：先发制人——多个技能同时作用时优先结算，且主动技能不会被反制。

主动技能：强攻、压制、掠夺、破釜沉舟。

 

【保守者】

被动：稳如泰山——受到负面效果减少30%，每局自动免疫一次攻击。

主动技能：止损、铁壁、反击、守护。

 

【幸运者】

被动：气运加身——随机负面效果伤害减少50%，随机正面效果额外+2。

主动技能：好运降临、避霉运、豪赌、天选。

 

【情报者】

被动：情报网——情报阶段可看到所有待公开信息及操作痕迹，且自己的信息免疫其他情报者的破坏技能。

主动技能：窥探、伪造、清除、审查、公证。

五、情报系统

1. 发布信息：玩家可以公布自己的身份、技能/策略或分数。

2. 待公开信息：发布后不会立刻公开，而是进入待公开状态。

3. 情报阶段：如果有待公开信息，会先进入短暂情报阶段。

4. 情报者处理：情报者可以窥探身份、伪造信息、清除信息、阻止发布、公证保护。

5. 正式公开：情报阶段结束后，剩余信息才会正式显示在情报板上。

6. 同行免疫：情报者之间不能互相清除或伪造信息，但审查、窥探仍然有效。

六、玩法提示

1. 讨论阶段很重要：可以用承诺和威胁影响别人，也可以说谎。

2. 情报信息不一定可信：看到 ⚠️ 或伪造标记时要谨慎。

3. 职业搭配不同：激进者适合进攻，保守者适合防守，幸运者适合随机事件，情报者适合信息战。

4. 每个主动技能每轮一般只能使用一次，开局前选好的 2~3 个技能会决定你的打法。

七、常见问题

Q：为什么我看不到别人的真实身份？

A：身份是隐藏信息，只有情报者的“窥探”等技能才能查看。

Q：为什么发布信息后没有立刻显示？

A：需要先经过情报阶段，情报阶段结束后才会正式公开。

Q：机器人会玩吗？

A：机器人会自动发布信息和发动技能，可以作为练习对手。

Q：页面看起来还是旧版？

A：请按 Ctrl+Shift+R 强制刷新，或使用无痕窗口。
